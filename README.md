# ANT System

**ANT** (Archive Nesting Technique) is an organizational method system for managing files and folders with consistency, clarity, and automation-friendly structure.

It defines how storage units should be created, named, and maintained — so that even with large amounts of files, everything stays organized, searchable, and scalable.

📘 **Full documentation:** https://ant-system.vercel.app/en/introduction/what-is-ant/

---

## 🚀 Quick Start

The fastest way to get started is through the included utilities.

**1. Download and run NewStorageWizard**
It will generate a ready-to-use ANT-compliant storage structure automatically.

🔽 [Download NewStorageWizard.exe](https://github.com/MikeWorldYt/ANT-system/raw/main/Applications/NewStorageWizard/dist/NewStorageWizard.exe)

The wizard creates your root directory with the standard top-level structure:

```
📁 Your_Root
 ├── 📁 100.PERSONAL
 ├── 📁 200.WORK
 ├── 📁 300.PROJECTS
 ├── 📁 400.ACADEMIC
 ├── 📁 500.HOBBIES
 ├── 📁 900.Resources
 ├── 📁 998.Review
 └── 📁 999.Settings
```

**2. Use FolderManager to maintain it**
Once your structure is live, FolderManager lets you organize, rename, and manage it without touching the terminal.

🔽 [Download FolderManager.exe](https://github.com/MikeWorldYt/ANT-system/raw/main/Applications/FolderManager/dist/FolderManager.exe)

> For a full walkthrough including migration from an existing setup, see [Getting Started](https://ant-system.vercel.app/en/start-here/getting-started).

## 🧩 Core Principles

ANT is built on three components:

**ANT Naming Format** — A strict, rule-based naming convention. Files and folders follow predictable patterns (Block, Chill, and Control Naming) that make them readable, sortable, and easy to retrieve via any OS search.

Example:
```
300.PROJECTS / PRJ001_(25-06)Academic_[MikeWorld]_Thesis-Draft
```

**Storage Structure Rules** — Guidelines for how directories should be organized hierarchically, using numbered categories that mirror a DAG-adapted tree structure.

**Utility Tools** — Small applications that automate common ANT tasks: initializing storage units, managing folders, and batch renaming files.
