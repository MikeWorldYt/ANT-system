# Worknodes

- A worknode (WKB) is a project folder: `PJ.` project, `PR.` practice, `HW.` homework, `CR.` course, `TK.` task, then a number and a title (`PJ.001_Web`). `add_worknode` numbers it for you.
- `00.` next to worknodes is the level's Portfolio; its title can change, its id cannot.
- `set_type` makes a folder a NODE or a WKB; `set_status` sets a worknode's status; `set_board` places worknodes in the task board's columns and order.
- `set_owner`, `set_favorite`, `set_important` and `hide` mark folders.
