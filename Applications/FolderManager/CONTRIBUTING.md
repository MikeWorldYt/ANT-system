## Sign-off (Developer Certificate of Origin)

Every commit must include a `Signed-off-by` line. With it you certify the
Developer Certificate of Origin 1.1 below.

Add it with:

```sh
git commit -s -m "fix(fm-ui): Example change"
```

This appends a line like:

```
Signed-off-by: Your Name <your.email@example.com>
```

Use your real name or a name you are known by, and an email you can be
reached at. Pull requests with unsigned commits may be asked to add a sign-off
before they are merged. To sign off earlier commits, use
`git rebase --signoff` or amend them with `git commit --amend -s`.
