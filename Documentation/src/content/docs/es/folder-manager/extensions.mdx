Las extensiones son pequeños complementos en JavaScript que corren aislados de la app. Cada una pide permisos, que la app lista antes de instalarla:

<ImagePlaceholder label="Captura: Extensiones" />

- Leer los nombres, tipos y estados de tus carpetas.
- Añadir opciones al menú contextual.
- Mostrar su propio panel.
- Mostrar campos extra en el panel de detalles.

Instala desde la **Library** (validada por los desarrolladores de ANT) o pega una dirección pública de GitHub en **Add from a repository**. Las extensiones de un repositorio se marcan como no validadas: instala solo código de un autor en quien confíes. Cada extensión instalada tiene un interruptor para apagarla y un botón **Remove**.
