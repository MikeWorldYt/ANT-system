Al abrir, la app compara su versión con la última publicada en su canal de actualizaciones de GitHub Releases (un pequeño archivo `latest.json`), salvo que hayas desactivado **Check for updates automatically** en About. Una versión es más nueva según sus números, y un release gana a su propio `-beta`. Si el canal no responde, no hay actualización. **Check for updates** en About hace la comprobación cuando quieras, incluso para una versión omitida.

- **Receive beta updates:** activado, la app sigue `folder-manager-latest`, que lleva todas las versiones, betas incluidas. Desactivado, sigue `folder-manager-stable`, que solo lleva versiones sin `-beta`. Empieza activado si instalaste una beta y desactivado si instalaste una versión estable. Si lo desactivas en una beta, te quedas en tu versión hasta que salga una estable más nueva.
- **Install updates automatically:** activado por defecto. Cuando la comprobación al abrir encuentra una versión más nueva, la app la instala sin preguntar y se cierra para aplicarla. Desactivado, pregunta: **Update**, **Remind me later** o **Skip version**. Una comprobación desde About siempre pregunta.

- **Windows:** FolderManager se instala como cualquier otro programa. Update descarga `FolderManager_installer.exe` del release de GitHub correspondiente (`folder-manager-v<versión>`), con la dirección y el SHA-256 que lista `latest.json`. Verifica el instalador contra ese SHA-256 (y contra el digest de la API de Releases, cuando responde) y luego lo ejecuta directamente. Si falta un valor o la verificación falla, la actualización se detiene y la app sigue abierta.
- **Copia portable:** ya no se reemplaza sola. Instala la app con el instalador o descarga la versión nueva desde la [página de Descargas](/es/start-here/download).
- **Linux y macOS:** la actualización desde la app no está disponible. Descarga el archivo nuevo desde la [página de Descargas](/es/start-here/download) y reemplaza el anterior.
