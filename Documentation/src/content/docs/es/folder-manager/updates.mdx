Al abrir, la app compara su versión con la publicada en GitHub, salvo que hayas desactivado **Check for updates automatically** en About. Si hay una más nueva, elige **Update**, **Remind me later** o **Skip version**. **Check for updates** en About hace la comprobación cuando quieras, incluso para una versión omitida.

<ImagePlaceholder label="Captura: Actualizaciones" />

- **Windows:** FolderManager se instala como cualquier otro programa. Update descarga `FolderManager_installer.exe` del release de GitHub correspondiente (`folder-manager-v<versión>`), verifica su SHA-256 con el digest que GitHub lista para ese archivo y luego ejecuta el instalador directamente. Si el release no trae digest, o la verificación falla, la actualización se detiene y la app sigue abierta.
- **Copia portable:** ya no se reemplaza sola. Instala la app con el instalador o descarga la versión nueva desde la [página de Descargas](/es/start-here/download).
- **Linux y macOS:** la actualización desde la app no está disponible. Descarga el archivo nuevo desde la [página de Descargas](/es/start-here/download) y reemplaza el anterior.
