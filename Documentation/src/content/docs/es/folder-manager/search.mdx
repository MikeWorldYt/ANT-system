Pulsa `Ctrl+F` para enfocar el cuadro de búsqueda y escribe palabras para buscar en los nombres de carpeta. Los filtros acotan el resultado:

<ImagePlaceholder label="Captura: Búsqueda" />

| Filtro | Ejemplo | Encuentra |
| --- | --- | --- |
| `in:` | `in:200.WORK` | Solo dentro de esa carpeta |
| `status:` | `status:in-progress` | Tableros con ese estado |
| Cualquier clave de `info.json` | `owner:Mike` | Carpetas cuyo `info.json` tenga ese valor. `client:` y `holder:` cuentan como `owner:` |

Mientras escribes un filtro como `in:` o `status:`, la app sugiere valores. Elige uno, o escribe un espacio tras un valor completo, para convertirlo en una etiqueta. Entrecomilla los valores con espacios, como `owner:"Mike W"`. Elige un resultado para saltar a esa carpeta en el árbol. `Retroceso` en el cuadro vacío quita la última etiqueta y `Esc` cierra los resultados.
