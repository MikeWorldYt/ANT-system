Folder Manager (ANT System Manager) es la app de escritorio para explorar un almacenamiento ANT, añadir nodos y worknodes, seguir el estado de tu trabajo y encontrar cualquier carpeta por nombre, tipo, estado o responsable. Es una app Tauri 2 (Rust y TypeScript) con versiones para Windows, Linux y macOS.

## Instalar y abrir

1. Descarga el archivo de tu sistema desde la [página de Descargas](/es/start-here/download).
2. **Instalador:** ejecuta `FolderManager_installer.exe` (Windows), el `.deb` (Linux) o el `.dmg` (macOS). **Portable:** ejecuta `FolderManager_portable.exe`, o extrae el `.tar.gz` y ejecuta el archivo de dentro.
3. La app necesita un almacenamiento ANT: una carpeta que contenga `999.Settings`. Si aún no tienes uno, mira [Primeros pasos](/es/start-here/getting-started).

### Cómo encuentra la app tu almacenamiento

Al iniciar, la app elige dónde buscar en este orden, y gana el primero que aplique:

1. Una ruta de carpeta pasada a la app como primer argumento.
2. El almacenamiento que contiene el ejecutable, para una copia portable puesta dentro de uno.
3. El almacenamiento que recordó la última vez que abrió, guardado por cada copia de la app fuera de tu almacenamiento.
4. La carpeta desde la que se inició la app, si esa carpeta o su carpeta superior contiene `999.Settings`.

Si no encuentra ningún almacenamiento, se abre la pantalla **Storages**: elige uno que abriste antes, abre una carpeta de almacenamiento existente o crea uno nuevo vacío. En Windows un almacenamiento nuevo va en el disco que elijas; en el disco del sistema queda en tu carpeta de usuario. Cada almacenamiento de la lista tiene un menú para renombrarlo, moverlo, mostrarlo en el explorador o quitarlo de la lista. Puedes volver a esa pantalla desde **Settings → Storage → Switch**.

Si la base de datos no se puede leer, la app pregunta qué hacer:

- **Other Storage:** abre la pantalla Storages.
- **Scan Storage:** vuelve a leer las carpetas del disco. Una `ant.db` ilegible se aparta antes.
- **Use backup:** aparece cuando falta la base de datos y hay un respaldo en la carpeta de respaldos por defecto. Mira [Respaldos](/es/folder-manager/backups).
