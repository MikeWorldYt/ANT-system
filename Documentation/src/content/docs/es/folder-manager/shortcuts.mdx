En macOS usa `Cmd` en lugar de `Ctrl`. En otros sistemas también sirve `Win` o `Super`.

<ImagePlaceholder label="Captura: Atajos de teclado" />

| Atajo | Acción | Editable |
| --- | --- | --- |
| `Ctrl+F` | Buscar en el almacenamiento | Sí |
| `Ctrl+L` | Editar la ruta | Sí |
| `Ctrl+N` | Nuevo nodo junto a la selección | Sí |
| `Ctrl+Alt+N` | Nuevo tablero junto a la selección | Sí |
| `Ctrl+,` | Abrir los ajustes | Sí |
| `Alt+Arriba` | Ir a la carpeta superior | Sí |
| `Enter` | Abrir la carpeta seleccionada | No |
| `Delete` | Eliminar la carpeta seleccionada | No |
| `F2` | Renombrar la carpeta seleccionada | No |
| `Alt+Izquierda`, `Alt+Derecha` | Atrás y adelante en el historial de selección | No |
| `Shift+F10` | Abrir el menú contextual | No |

`Enter` y `Delete` actúan solo en las vistas de carpetas, nunca mientras escribes en un campo. Para cambiar un atajo editable, mira [Ajustes](/es/folder-manager/settings).
