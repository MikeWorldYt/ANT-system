Elige tu sistema y haz clic en un enlace para descargar. No hay nada que instalar: cada herramienta es un solo archivo. Para los pasos de configuración, mira [Primeros Pasos](/es/start-here/getting-started/).

## CreateNewStorage

Una pequeña herramienta de línea de comandos que crea por ti un almacenamiento ANT listo para usar. Última versión: 3.1.0.

| Plataforma | Archivo |
| --- | --- |
| <Icon name="seti:windows" size="1.1em" /> Windows | [CreateNewStorage.exe](https://github.com/MikeWorldYt/ANT-system/releases/download/create-new-storage-v3.1.0/CreateNewStorage.exe) |
| <Icon name="linux" size="1.1em" /> Linux | [CreateNewStorage-linux.tar.gz](https://github.com/MikeWorldYt/ANT-system/releases/download/create-new-storage-v3.1.0/CreateNewStorage-linux.tar.gz) |
| <Icon name="apple" size="1.1em" /> macOS | [CreateNewStorage-macos.tar.gz](https://github.com/MikeWorldYt/ANT-system/releases/download/create-new-storage-v3.1.0/CreateNewStorage-macos.tar.gz) |

## FolderManager

Una app de escritorio para explorar y organizar tu almacenamiento con vistas de árbol y columnas, renombrar carpetas, seguir su estado y buscar. Última versión: 2.2.1. Mira [Folder Manager](/es/tools/folder-manager/) para saber cómo usarla.

| Plataforma | Archivo |
| --- | --- |
| <Icon name="seti:windows" size="1.1em" /> Windows | [FolderManager.exe](https://github.com/MikeWorldYt/ANT-system/releases/download/folder-manager-v2.2.1/FolderManager.exe) |
| <Icon name="linux" size="1.1em" /> Linux | [FolderManager-linux.tar.gz](https://github.com/MikeWorldYt/ANT-system/releases/download/folder-manager-v2.2.1/FolderManager-linux.tar.gz) |
| <Icon name="apple" size="1.1em" /> macOS | [FolderManager-macos.tar.gz](https://github.com/MikeWorldYt/ANT-system/releases/download/folder-manager-v2.2.1/FolderManager-macos.tar.gz) |

## Reformatter

Renombra muchos archivos existentes de una vez al formato de nombres de ANT, con una vista previa antes de cambiar nada. Solo para Windows. Última versión: 0.2.1.


| Plataforma | Archivo |
| --- | --- |
| <Icon name="seti:windows" size="1.1em" /> Windows | [reformatter.v.0.2.1.exe](https://github.com/MikeWorldYt/ANT-system/releases/download/v0.2.1/reformatter.v.0.2.1.exe) |
