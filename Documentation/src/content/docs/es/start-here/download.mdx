Elige tu sistema y haz clic en un enlace para descargar. No hay nada que instalar: cada herramienta es un solo archivo. Para los pasos de configuración, mira [Primeros Pasos](/es/start-here/getting-started/).

## CreateNewStorage

Una pequeña herramienta de línea de comandos que crea por ti un almacenamiento ANT listo para usar. Última versión: 3.1.0.

## FolderManager

Una app de escritorio para explorar y organizar tu almacenamiento con vistas de árbol y columnas, renombrar carpetas, seguir su estado y buscar. Última versión: 2.4.5-beta. El instalador deja la app lista para tu usuario sin permisos de administrador; el portable funciona desde cualquier carpeta, también dentro de un almacenamiento. Mira [Folder Manager](/es/folder-manager) para saber cómo usarla.

| Plataforma | Instalador | Portable |
