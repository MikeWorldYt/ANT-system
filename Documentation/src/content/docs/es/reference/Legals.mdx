## Método abierto

Los procesos de categorización de ANT se inspiraron en sistemas como el DDC y el UDC. El método descrito en esta documentación es y seguirá siendo de libre acceso para todas las personas. Así lo decidieron quien lidera el proyecto y sus participantes, y se espera que siga así.
