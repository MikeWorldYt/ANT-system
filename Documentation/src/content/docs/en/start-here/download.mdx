## FolderManager

A desktop app to browse and organize your storage with tree and column views, rename folders, track status and search. Latest version: 2.5.2. The installer sets the app up for your user with no admin rights; the portable file runs from anywhere, also from inside a storage. See [Folder Manager](/en/folder-manager) for how to use it.
