## Quick Start

### 1. Create a new ANT-Storage

<Tabs syncKey="os">
  <TabItem label="Windows">

    <div style="display: flex; align-items: center; gap: 0.5rem;">
      <img src="https://cdn.jsdelivr.net/gh/devicons/devicon/icons/windows8/windows8-original.svg" width="26" height="26" />
      <h3 style="margin: 0;">windows CLI</h3>
    </div>

    1.1 DOWNLOAD:

    ```powershell
    Invoke-WebRequest -Uri https://github.com/MikeWorldYt/ANT-system/releases/download/create-new-storage-v3.2.0/CreateNewStorage.exe -OutFile CreateNewStorage.exe
    ```
    [Direct download for Windows](https://github.com/MikeWorldYt/ANT-system/releases/download/create-new-storage-v3.2.0/CreateNewStorage.exe)

    1.2. INSTALL AND OPEN:

    ```powershell
    # Variables
    $MY_STORAGE = "My-name-storage"       # <-- Change the name to yours e.g. William

    # Install and open
    .\CreateNewStorage.exe $HOME --name "$MY_STORAGE"
    explorer "$HOME\$MY_STORAGE"
    ```
    <Callout type="warning" title="Attention">
      Change the variable **MY_STORAGE** to your desired name before running the commands.
    </Callout>

  </TabItem>
  <TabItem label="Linux">

    <div style="display: flex; align-items: center; gap: 0.5rem;">
      <img src="https://cdn.jsdelivr.net/gh/devicons/devicon/icons/linux/linux-original.svg" width="26" height="26" />
      <h3 style="margin: 0;">linux CLI</h3>
    </div>
    1.1 DOWNLOAD: 

    ```bash
    curl -L -o cns.tar.gz https://github.com/MikeWorldYt/ANT-system/releases/download/create-new-storage-v3.2.0/CreateNewStorage-linux.tar.gz
    tar -xzf cns.tar.gz        # extracts the CLI executable
    ```
    [Direct download for Linux](https://github.com/MikeWorldYt/ANT-system/releases/download/create-new-storage-v3.2.0/CreateNewStorage-linux.tar.gz)

    1.2. INSTALL AND OPEN:

    ```sh
    # Variables
    MY_STORAGE="My-name-storage"       # <-- Change the name to yours e.g. William

    # Install and open
    ./create-new-storage ~ --name "\$MY_STORAGE"
    xdg-open ~/"\$MY_STORAGE"
    ```
    <Callout type="warning" title="Attention">
      Change the variable **MY_STORAGE** to your desired name before running the commands.
    </Callout>

  </TabItem>

### 2. Open FolderManager

CreateNewStorage leaves **FolderManager** in your new storage. 
Open it to start: it shows a suggested structure that you can adjust to whatever suits you. Read more in [Folder Manager](/en/tools/folder-manager).

![FolderManager opening on the suggested structure, then switching views, deleting, renaming and changing folder types](https://r2.mikeworld.dev/folder-manager/first-run.gif)

### 3. Migrate your files

After initializing, you can begin [**migrating**](/en/start-here/migrating-plan) **your existing files** into the new system.
