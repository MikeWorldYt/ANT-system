On open, the app compares its version with the latest one published on its update channel in GitHub Releases (a small `latest.json` file), unless you turned off **Check for updates automatically** in About. A release counts as newer by its version numbers, and a release beats its own `-beta`. If the channel does not answer, there is no update. **Check for updates** in About runs the check on demand, even for a skipped version.

- **Receive beta updates:** on, the app follows `folder-manager-latest`, which carries every version, betas included. Off, it follows `folder-manager-stable`, which carries only versions without `-beta`. It starts on when you installed a beta and off when you installed a stable version. Turning it off on a beta keeps your version until a newer stable one comes out.
- **Install updates automatically:** on by default. When the check at open finds a newer version, the app installs it without asking and closes to apply it. Off, it asks: **Update**, **Remind me later** or **Skip version**. A check you run from About always asks.

- **Windows:** FolderManager installs like any other program. Update downloads `FolderManager_installer.exe` from the matching GitHub release (`folder-manager-v<version>`), using the address and SHA-256 listed in `latest.json`. It checks the installer against that SHA-256 (and against the digest of the Releases API, when it answers) and then runs the installer directly. If a value is missing or the check fails, the update stops and the app stays open.
- **Portable copy:** it no longer replaces itself. Install the app with the installer, or download the new version from the [Downloads page](/en/start-here/download).
- **Linux and macOS:** the in-app update is not available. Download the new archive from the [Downloads page](/en/start-here/download) and replace the old file.
