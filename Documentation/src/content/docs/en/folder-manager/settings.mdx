Open the settings window with the gear button next to the storage name, or press `Ctrl+,`. It has one page per group. Changes apply right away.

<ImagePlaceholder label="Screenshot: Settings" />

| Page | What you can do |
| --- | --- |
| General | Pin favorites to the top of each list. Hide worknodes with status done. Choose what to open on launch (continue where you left off, or the root) and the starting view (continue, Tree or Columns). Turn **Confirm before deleting** on or off. Turn **Batch drops join their group** on (default) or off. |
| Appearance | Theme (System, Light, Dark), accent color and text size (Small, Medium, Large). |
| Shortcuts | Edit the six editable shortcuts: press **Edit**, then the new keys, or `Esc` to cancel. A shortcut needs `Ctrl` or `Alt` with a key, without `Shift`, and cannot reuse another shortcut or a fixed one. **Reset** restores the defaults. |
| Storage | Rename the storage folder, with a log and **Revert last rename**, and see where the storage is. **Reindex Storage** after moving files outside the app. **Watch for external changes** checks once a day. |
| Backup | Automatic backup, its frequency and folder, and export and import. See [Backups](/en/folder-manager/backups). |
| Extensions | Add, enable, disable and remove extensions. See [Extensions](/en/folder-manager/extensions). |
| Advanced | Debug logging, open the logs folder, open the developer tools, **Let AI agents change this storage** (see below) and reset preferences. See [Troubleshooting](/en/folder-manager/troubleshooting#troubleshooting). |
| About | App version, storage path, update check, the automatic check toggle, documentation, changelog and **Report a bug** (a prefilled issue on GitHub, or an email to `info@mikeworld.dev`). |

Renaming the storage folder changes its path, so close any program that reads it first. The daily **Watch for external changes** check runs as a scheduled task, which is only available on Windows for now.

## AI agents are read-only by default

An assistant connected through MCP can only read your storage until you turn on **Let AI agents change this storage** in **Advanced**. Until then, every tool that changes something refuses and nothing is modified. The switch belongs to each storage, asks you to confirm when you turn it on, and **Reset preferences** turns it off again. See [Connect your AI](/en/folder-manager/connect-ai).

With it on, the assistant can create, rename and change folders, but some changes still wait for your yes in the FolderManager window:

- Deletes, moves, reordering, applying or undoing a project sort, deleting a file and replacing the dictionary.
- Any call that changes several items at once, such as several board cards.

The window asks for 60 seconds. If you decline, let it time out, keep the window hidden or have another storage open, nothing changes. Keep the window visible while the assistant works. One call is also limited to 50 board cards, 50 project plans and 500 files; a larger one is refused before anything runs.

Folder and file names that the assistant reads are marked as storage data, not as instructions.
