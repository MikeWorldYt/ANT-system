## Estructura de datos de árbol
Es un tipo de dato abstracto muy utilizado que representa una estructura jerárquica de árbol mediante un conjunto de nodos conectados. Cada nodo del árbol puede estar conectado a muchos hijos, pero debe estar conectado exactamente a un padre, excepto el nodo raíz, que no tiene padre.
