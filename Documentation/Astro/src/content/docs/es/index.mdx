## Cómo funciona

ANT (Archive Nesting Technique) combina tres cosas: una estructura de carpetas numerada, un formato de nombres estricto y pequeñas herramientas que la crean por ti.

<CardGrid stagger>
	<Card title="Estructura de carpetas" icon="seti:folder">
		Niveles y módulos numerados (`100.PERSONAL`, `200.WORK`, `300.PROJECTS`…) que mantienen el árbol poco profundo y predecible.
	</Card>
	<Card title="Nomenclaturas" icon="pencil">
		Nombres Chill, Block y Control. Un nombre como `PJ.001_Thesis-Draft` dice qué es y cuál es; la fecha y el dueño van en sus metadatos.
	</Card>
	<Card title="Nodos de soporte" icon="setting">
		Carpetas fijas en cada nivel para configuración, revisión, plantillas, recursos y trabajos terminados, para que nada se acumule en el escritorio.
	</Card>
	<Card title="Utilidades" icon="rocket">
		Herramientas para Windows que crean tu estructura raíz y la mantienen ordenada sin usar la terminal.
	</Card>
</CardGrid>
