Welcome to the ANT documentation! 🐜

ANT is a organizational methods system designed to streamline the storage, project management and file retrieval.

## Create a new ANT-system
### Quick Start

1. Download [CreateNewStorage](https://github.com/MikeWorldYt/ANT-system/raw/main/Applications/CreateNewStorage/dist/CreateNewStorage.exe)
2. Follow your browser's prompts to save and open CreateNewStorage
3. Once open, follow the prompts to create a new ANT-system
4. After initializing, you can being [**migrating**](/en/start-here/migrating-plan) **your existing files** into the new system.

### Step-by-Step Instructions

<Callout type="warning">
  We strongly recommend that you use **CreateNewStorage** to avoid doing it manually.
</Callout>

1. Choose a Root location

2. Name the Root Directory  
Create a descriptive name like:   
- `My_Files`
- `Home_Files`
- `Rick_Files`

3. Create a basic structure
Open the root directory and create the following folders:

```
📁 You_Root
 ├── 📁 100.PERSONAL
 ├── 📁 200.WORK
 ├── 📁 300.PROJECTS
 ├── 📁 400.ACADEMIC
 ├── 📁 500.HOBBIES
 ├── 📁 900.Resources
 ├── 📁 998.Review (Index)
 └── 📁 999.Settings

```
