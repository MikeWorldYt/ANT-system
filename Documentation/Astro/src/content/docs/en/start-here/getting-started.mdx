Welcome to the ANT documentation! 🐜

ANT is a organizational methods system designed to streamline the storage, project management and file retrieval.

## Quick Start

### 1. Create a new ANT-Storage

<Tabs syncKey="os">
  <TabItem label="Windows">
    ```powershell
    # PowerShell
    Invoke-WebRequest -Uri https://github.com/MikeWorldYt/ANT-system/releases/download/create-new-storage-v3.1.0/CreateNewStorage.exe -OutFile CreateNewStorage.exe
    .\CreateNewStorage.exe --help
    .\CreateNewStorage.exe $HOME --name "My-name-storage"   # change the name to yours
    ```
  </TabItem>
  <TabItem label="Linux">
    ```bash
    curl -L -o cns.tar.gz https://github.com/MikeWorldYt/ANT-system/releases/download/create-new-storage-v3.1.0/CreateNewStorage-linux.tar.gz
    tar -xzf cns.tar.gz        # extracts the "create-new-storage" executable, already runnable
    ./create-new-storage --help
    ./create-new-storage ~ --name "My-name-storage"   # change the name to yours
    ```
  </TabItem>
  <TabItem label="macOS">
    ```bash
    curl -L -o cns.tar.gz https://github.com/MikeWorldYt/ANT-system/releases/download/create-new-storage-v3.1.0/CreateNewStorage-macos.tar.gz
    tar -xzf cns.tar.gz        # extracts the "create-new-storage" executable, already runnable
    ./create-new-storage --help
    ./create-new-storage ~ --name "My-name-storage"   # change the name to yours
    ```
  </TabItem>
</Tabs>

The first argument is where the storage goes, and `--name` creates a sanitized subfolder inside it. 
If you prefer a [direct download](/en/start-here/download).

### 2. Open FolderManager

CreateNewStorage leaves **FolderManager** in your new storage. 
Open it to start: it shows a suggested structure that you can adjust to whatever suits you. Read more in [Folder Manager](/en/tools/folder-manager).

![FolderManager opening on the suggested structure, then switching views, deleting, renaming and changing folder types](/media/folder-manager-first-run.gif)

### 3. Migrate your files

After initializing, you can begin [**migrating**](/en/start-here/migrating-plan) **your existing files** into the new system.

## Manual Storage creation

<Callout type="warning">
  We strongly recommend that you use **CreateNewStorage** to avoid doing it manually.
</Callout>

### 1. Create a Root

Choose a root location, for example:

<Tabs syncKey="os">
  <TabItem label="Windows">
    ```powershell
    # Change by your root name before
    New-Item -Path "D:\root-name" -ItemType Directory
    ```
  </TabItem>
  <TabItem label="Linux">
    ```bash
  # Change by your root name before
    sudo mkdir /root-name
    ```
  </TabItem>
</Tabs>

Create a descriptive name for example: 
- `My_Files`
- `Rick_Files`

### 2. Create a basic structure
Open the root directory and create the following folders:

```
📁 My_Files
 ├── 📁 100.PERSONAL
 ├── 📁 200.WORK
 ├── 📁 300.PROJECTS
 ├── 📁 400.ACADEMIC
 ├── 📁 500.HOBBIES
 ├── 📁 900.Resources
 ├── 📁 998.Review (Index)
 └── 📁 999.Settings

```
