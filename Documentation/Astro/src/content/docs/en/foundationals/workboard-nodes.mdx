title: Workboard Nodes
---

Temporary project repositories designed with to containing all files related for tasks, projects, or practices. These nodes prevent that files get scattered assets (e.g., between Downloads, Desktop, or random drives) by providing a explicit and temporary workspaces for them.

### Naming Convention for Workboards 
Structured as multi-component identifiers for instant recognition:

`<Type>.<Traker>_(<Date>) <Breadcrumb> [<Holder>]_<Name>`

| Element       |  Description                                           |
|---------------|--------------------------------------------------------|
| **Type**      | `PJ.` `PR.` `HW` `TK`   Its their type of workboard                |
| **Traker**    | 3-digit incremental   Sequence counter (001, 002...)       |
| **Date**      | `(YY-MM-DD)`      Project initiation date              |
| **Breadcrumb**| Category tag     Project group (vlogs, tutorials etc) |
| **Holder**    | Refers to owner (client, organization, school, etc) or reference name, within brackets.  |
| **Name**      | Descriptive name, use Train Case |

**Example:**  
`PJ.005_(24-03-30) Tutorial [MikeWorldYt]_Organize Documents With INSANE Efficiency`

#### Types of Workboards
- **PJ:** Project
- **PR:** Practice
- **HW:** Homework
- **TK:** Task
