## How it works

ANT (Archive Nesting Technique) combines three things: numbered folder structure, a strict naming format and small tools that set it up for you.

<CardGrid stagger>
	<Card title="Folder structure" icon="seti:folder">
		Numbered levels and modules (`100.PERSONAL`, `200.WORK`, `300.PROJECTS`…) that keep the tree shallow and predictable.
	</Card>
	<Card title="Naming conventions" icon="pencil">
		Chill, Block and Control naming. A name like `PRJ001_(25-06)Academic_[MikeWorld]_Thesis-Draft` tells you what, when and for whom.
	</Card>
	<Card title="Support nodes" icon="setting">
		Fixed folders on every level for settings, review, templates, resources and finished work, so nothing piles up on the desktop.
	</Card>
	<Card title="Utilities" icon="rocket">
		Windows tools that create your root structure and keep it tidy without touching the terminal.
	</Card>
</CardGrid>

## Your root, ready in minutes

📁 Your_Root

 ├── 📁 400.ACADEMIC
