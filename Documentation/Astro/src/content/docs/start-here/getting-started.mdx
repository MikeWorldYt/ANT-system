Welcome to the ANT documentation! 🐜

ANT is a organizational methods system designed to streamline the storage, project management and file retrieval.

## Create a new ANT-system
### Quick Start

1. Download Templ-ANT 
2. Follow your browser's prompts to save and open the Templ-ANT.exe 
3. Once open, follow the prompts to create a new ANT-system
4. After initializing, you can being [**migrating**](/start-here/migrating-plan) **your existing files** into the new system.

### Step-by-Step

1. Name the Root Directory  
Create a descriptive name like:   
- `My_Files`
- `Home_Files`
- `Rick_Files`
